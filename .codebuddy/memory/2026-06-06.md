## 二维码悬浮展示问题修复（最终方案）
- 用户需求：二维码向下悬浮展示，不能向上（会遮挡邮箱/GitHub）
- 最终方案：`position: fixed` + JS 动态定位 + `#contact` section 底部 padding:180px
- 关键参数：`.qr-body` width: `min(260px, calc(100vw - 32px))`，图片 `max-width: 200px`
- JS 定位逻辑：水平左对齐卡片，垂直始终在卡片下方（cardRect.bottom + 10）
- 之前尝试过的方案（已废弃）：
  - `absolute` 定位：被父容器裁剪
  - `fixed` + 自动切换上下方：用户体验差
  - 二维码图片过大（360px 容器）：缩小到 260px/200px 更合适
