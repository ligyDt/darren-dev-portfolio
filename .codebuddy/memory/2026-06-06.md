# 2026-06-06

## 二维码悬浮展示问题修复（最终方案）
- 用户需求：二维码向下悬浮展示，不能向上（会遮挡邮箱/GitHub），也不能左右切换（体验差）
- 最终方案：回到 `absolute` 定位 + 向下弹出，给 `#contact` section 增加 `padding-bottom: 220px` 预留空间
- CSS 关键技巧：
  - `.qr-body` 默认 `visibility: hidden` + `transition: visibility 0s 0.16s`（延迟隐藏，确保动画完成后再隐藏）
  - `.qr-card:hover .qr-body` 设置 `transition: visibility 0s 0s`（立即显示）
  - 移除了所有 JS 动态定位代码，纯 CSS 方案更简洁
- 之前尝试过的方案（已废弃）：
  - `position: fixed` + JS 动态计算位置：会同时遮挡上方和下方
  - 自适应方向（dir-down/dir-up/dir-left）：用户反馈来回切换体验差
